# Draw-with-palette-switched-off

使任意图片实现短视频中关掉调色板画画的效果

## 效果说明

短视频中流行的创作方式：画师选择一组颜色作为色盘，将屏幕设为黑白模式后作画。由于黑白模式下只能看到明暗关系，画完关掉黑白模式后会出现一幅色彩怪异但明暗光影关系完全自然的画。

本工具用代码自动复现这个效果——将图片每个像素的灰度亮度映射到自定义色盘中亮度匹配的颜色。

## 使用方法

1. 用浏览器打开 `index.html`
2. 拖放或点击上传一张图片
3. 在调色板区域选择自定义颜色，或点击「随机调色板」生成随机色盘
4. 效果图会自动生成，点击「下载效果图」保存结果

## 算法原理

1. 对每个像素计算 BT.709 灰度亮度值：`L = 0.2126R + 0.7152G + 0.0722B`
2. 将调色板中的颜色按亮度排序
3. 构建 256 级查找表（LUT），相邻颜色之间线性插值
4. 将每个像素的灰度值通过 LUT 映射到对应的调色板颜色，保留原始透明度

## 技术特点

- 纯前端实现，无需服务器，无外部依赖
- 单个 HTML 文件，直接用浏览器打开即可使用
- 支持拖放上传，响应式布局适配手机
- 实时预览，调色板修改后立即更新效果
